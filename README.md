# GMUPay – Secure Digital Payment and Expense Management System

## About the Project
GMUPay is a secure digital payment and expense management web application. It helps users perform transactions, manage payment activities, and track their expenses.

## Features
- User Registration and Login
- Email OTP Verification
- MPIN Authentication
- Fingerprint Authentication
- Money Transfer
- Transaction History
- Expense Categorization
- Expense Dashboard
- Notifications
- User Profile Management

## Technologies Used
- Frontend: React.js, TypeScript
- Backend: Node.js, Express.js
- Database: SQLite
- Styling: CSS

## Installation

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   `npm install`

4. Configure the required environment variables.
5. Run the project:

   `npm run dev`

6. Open the local URL displayed in the terminal.
